# CodeAlpha_Stock-grade-tracker-task-2
This project is a Java-based Stock Trading Simulator developed as part of an internship task. It allows users to buy and sell stocks, track their portfolio, and view performance in a simulated trading environment.

📌 Features
💰 Buy and sell stocks
📊 View available stock prices
📁 Track portfolio performance
🔄 Update balance after transactions
🧠 Object-Oriented Design (OOP)
💾 File handling (optional for saving data)
🛠️ Technologies Used
Java
OOP (Classes & Objects)
ArrayList / HashMap
File I/O (optional)
📂 Project Structure
Stock-Trading-Platform/
│
├── Main.java          # Main program execution
├── Stock.java         # Stock details
├── User.java          # User portfolio & balance
├── Transaction.java   # Buy/Sell logic
├── README.md
🚀 How to Run
1️⃣ Compile the program
javac Main.java
2️⃣ Run the program
java Main
💡 Sample Operations
View available stocks
Buy stocks
Sell stocks
Check balance
View portfolio
🧠 How It Works
Stocks are stored with name and price
User starts with an initial balance
User can buy/sell stocks
Portfolio updates automatically
Transactions are handled using OOP concepts
